# Comexio IO-Server Integration

Bring the power of your Comexio IO-Server to Home Assistant!
This custom component uses real-time local push (Webhooks) and dynamic Lua scripts to achieve maximum performance and reliability without polling.

## Features
- **Local Push:** Instant updates from Comexio without delay.
- **Deep Delta Sync:** Manages the Comexio logic automatically. Creates, updates, and deletes Web-IO configurations seamlessly.
- **Smart Diagnostics:** Suggests automated repairs directly in the Home Assistant UI when a Comexio setting was changed.
- **RSA Login:** Supports modern Comexio v11 firmware login logic.
